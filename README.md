This repository is an entry for the make.fun bounty "One Word, First Thought" (slug u-0xkianno-one-word-first-thought-106abaf8), submitting a single evocative and surprising word that captures a vivid physical action. The included TypeScript program reads the target output directory from the `MAKEFUN_OUTPUT_DIR` environment variable (falling back to `/output`), ensures the directory exists, and writes the exact 14-character word "defenestration" (the act of throwing someone or something out of a window) as UTF-8 text to `entry.txt` with no trailing newline or extra whitespace.
